# ប្រព័ន្ធគ្រប់គ្រងសៀវភៅសិក្សាគោល - កម្ពុជា 🇰🇭
### (Textbook Stock & Borrowing Management System with Google Sheets Multi-Device Database)

វេបសាយកម្មវិធីគ្រប់គ្រងសៀវភៅសិក្សាគោល និងប្រតិបត្តិការខ្ចី-សង សម្រាប់បណ្ណាល័យវិទ្យាល័យ និងអនុវិទ្យាល័យនៅកម្ពុជា។ ប្រព័ន្ធនេះប្រើប្រាស់ **Google Sheets** ធ្វើជា Cloud Database កណ្តាល តាមរយៈ **Google Apps Script API** ដែលអនុញ្ញាតឱ្យគ្រប់ឧបករណ៍ (**កុំព្យូទ័រ, ទូរស័ព្ទដៃ, Tablet, iPad**) អាចចូលប្រើប្រាស់ និងធ្វើបច្ចុប្បន្នភាពទិន្នន័យរួមគ្នាបានក្នុងពេលជាក់ស្តែង (Real-time Sync) ដោយឥតគិតថ្លៃ និងមិនចាំបាច់មាន Server ស្មុគស្មាញឡើយ!

## 🌟 លក្ខណៈពិសេសចម្បងៗ (Key Features)

### ១. មូលដ្ឋានទិន្នន័យ Google Sheets លើ Cloud (Multi-Device Shared Database)
- **ប្រើ Google Sheet ធ្វើជា Database កណ្តាល**៖ រាល់ទិន្នន័យទាំងអស់ (សៀវភៅ, សិស្ស, ប្រតិបត្តិការខ្ចី-សង, កំណត់ត្រា, ការកំណត់) ត្រូវបានបញ្ជូនទៅរក្សាទុកក្នុង Google Sheet លើ Google Drive របស់អ្នក។
- **ប្រើប្រាស់បានគ្រប់ Device ដំណាលគ្នា**៖ ទូរស័ព្ទដៃ, កុំព្យូទ័របណ្ណារក្ស, Tablet របស់លោកគ្រូអ្នកគ្រូ អាចមើលឃើញទិន្នន័យដូចគ្នាក្នុងពេលជាក់ស្តែង។
- **ស្វ័យប្រវត្តិកម្មនៃការធ្វើសមកាលកម្ម (Auto-Sync & Polling)**៖ ប្រព័ន្ធទាញទិន្នន័យថ្មីៗស្វ័យប្រវត្ត រៀងរាល់ ៣០ វិនាទី និងនៅពេលបើកអេក្រង់ឡើងវិញ (Auto-refresh on Tab Focus)។
- **សុវត្ថិភាពទិន្នន័យខ្ពស់ (Offline-First Fallback)**៖ ទោះបីជាដាច់អ៊ីនធឺណិតក៏ដោយ កម្មវិធីនៅតែអាចដំណើរការបានតាមរយៈ Local Storage ហើយនឹង Push ទៅកាន់ Google Sheet ដោយស្វ័យប្រវត្តិនៅពេលមានអ៊ីនធឺណិតឡើងវិញ។

### ២. ផ្ទាំងគ្រប់គ្រងទូទៅ (Dashboard)
- **សូចនាករគន្លឹះ (KPI Cards)**៖ បង្ហាញចំនួនចំណងជើងសៀវភៅសរុប, ចំនួនក្បាលសៀវភៅក្នុងស្តុក, សៀវភៅកំពុងខ្ចី, សៀវភៅសល់ជាក់ស្តែងលើធ្នើរ និងចំនួនសៀវភៅយឺតយ៉ាវហួសកាលកំណត់។
- **តារាងស្ថិតិ & ក្រាហ្វិក**៖ ក្រាហ្វិកបង្ហាញអត្រាខ្ចីតាមកម្រិតថ្នាក់ (ថ្នាក់ទី ៧ ដល់ ទី ១២) និងបញ្ជីប្រកាសអាសន្នសៀវភៅជិតអស់ពីស្តុក (Low Stock Alert)។
- **សកម្មភាពថ្មីៗ**៖ កត់ត្រាប្រតិបត្តិការខ្ចី និងសងចុងក្រោយបំផុតក្នុងពេលជាក់ស្តែង។

### ៣. គ្រប់គ្រងស្តុកសៀវភៅសិក្សាគោល (Books Inventory)
- គ្រប់គ្រងសៀវភៅពុម្ពសិក្សាគោលតាមកម្រិតថ្នាក់ (ថ្នាក់ទី ៧ ដល់ ទី ១២) និងមុខវិជ្ជា (ភាសាខ្មែរ, គណិតវិទ្យា, រូបវិទ្យា, គីមីវិទ្យា, ជីវវិទ្យា, ប្រវត្តិវិទ្យា...)។
- មុខងារ **បន្ថែម / កាត់បន្ថយស្តុកសៀវភៅរហ័ស** (Stock Adjustment)។
- បារបង្ហាញភាគរយស្តុក (Stock Level Indicator) និងផ្លាកសញ្ញាពណ៌ (គ្រប់គ្រាន់, ជិតអស់, អស់ពីស្តុក)។
- ស្វែងរកតាមចំណងជើង, មុខវិជ្ជា, ឬកូដសៀវភៅ ព្រមទាំងចម្រាញ់តាមកម្រិតថ្នាក់។

### ៤. ប្រតិបត្តិការខ្ចី និងប្រគល់សៀវភៅសង (Borrowings & Returns)
- **កត់ត្រាការខ្ចីថ្មី**៖ ជ្រើសរើសសិស្ស និងគូសធីកសៀវភៅដែលត្រូវខ្ចីបានច្រើនក្បាលក្នុងពេលតែមួយ។
- **គណនាកាលបរិច្ឆេទសងស្វ័យប្រវត្តិ**៖ ផ្អែកលើរយៈពេលខ្ចីកំណត់ក្នុងប្រព័ន្ធ (លំនាំដើម ១៤ ថ្ងៃ)។
- **ប្រព័ន្ធដាស់តឿនហួសកំណត់ (Overdue Tracking)**៖ ផ្លាស់ប្តូរស្ថានភាពទៅជា "ហួសកាលកំណត់" ស្វ័យប្រវត្តិនៅពេលដល់ថ្ងៃកំណត់។
- **កត់ត្រាការសង**៖ អាចជ្រើសរើសសងសៀវភៅទាំងអស់ ឬសងដោយផ្នែក (Partial Return)។
- **បោះពុម្ភបង្កាន់ដៃខ្ចីសៀវភៅ (Borrow Voucher)**៖ ទម្រង់បង្កាន់ដៃផ្លូវការសម្រាប់ឱ្យសិស្សចុះហត្ថលេខាទទួល និងរក្សាទុកជាភស្តុតាង។

### ៥. បញ្ជីឈ្មោះសិស្សានុសិស្ស (Students Directory)
- គ្រប់គ្រងអត្តលេខសិស្ស, ឈ្មោះ, ភេទ, ថ្នាក់, បន្ទប់, និងលេខទូរស័ព្ទ។
- **មើលប្រវត្តិខ្ចី-សង** ផ្ទាល់ខ្លួនរបស់សិស្សម្នាក់ៗ។
- **នាំចូលទិន្នន័យ (Import)** និង **នាំចេញទិន្នន័យ (Export)** ជាឯកសារ Excel / CSV បានយ៉ាងរហ័ស។

### ៦. មជ្ឈមណ្ឌលរបាយការណ៍ស្តង់ដារក្រសួង (Official MoEYS Reports)
- ទម្រង់ក្បាលលិខិតផ្លូវការ៖ **ព្រះរាជាណាចក្រកម្ពុជា ជាតិ សាសនា ព្រះមហាក្សត្រ** និងប្លុកហត្ថលេខាពីរជាន់ (នាយកសាលា & បណ្ណារក្ស)។
- ប្រភេទរបាយការណ៍ ៤ សម្បូរបែប៖
  1. **បញ្ជីសិស្សខ្ចីសៀវភៅ** (Borrowing List)
  2. **របាយការណ៍ស្តុកសៀវភៅ** (Stock Balance Report)
  3. **បញ្ជីសិស្សយឺតយ៉ាវហួសកាលកំណត់** (Overdue Students List)
  4. **ស្ថិតិសង្ខេបជូននាយក/ការិយាល័យអប់រំ** (Statistical Summary)
- ឧបករណ៍រៀបចំរបាយការណ៍ (Report Organizer)៖ ជ្រើសរើសកាលបរិច្ឆេទរហ័ស (ថ្ងៃនេះ, សប្តាហ៍នេះ, ខែនេះ, ឆមាសទី១, ឆមាសទី២), បង្ហាញ/លាក់ជួរឈរតាមបំណង, កែចំណងជើងផ្ទាល់ខ្លួន។
- **នាំចេញបានច្រើនទម្រង់**៖ បោះពុម្ភ / រក្សាទុកជា PDF (ទំហំ A4), ទាញយកជា Excel (CSV), និងចម្លងតារាង (Copy Table) យកទៅបិទភ្ជាប់ក្នុង Microsoft Word។

## 🛠️ របៀបតម្លើង Google Sheets Database (Setup Instructions)

អនុវត្តតាមជំហានងាយៗខាងក្រោម ដើម្បីបង្កើត Cloud Database ដោយឥតគិតថ្លៃ៖

### ជំហានទី ១៖ បង្កើត Google Sheet ថ្មី
1. ចូលទៅកាន់ [Google Sheets](https://sheets.new) (ឬ sheets.google.com)
2. បង្កើត Spreadsheet ថ្មីមួយ រួចដាក់ឈ្មោះថា៖ `BookStock_Database`

### ជំហានទី ២៖ បើក Apps Script
1. នៅលើ Menu ខាងលើនៃ Google Sheet ចុចលើ **Extensions** (ផ្នែកបន្ថែម) ➔ ជ្រើសរើស **Apps Script**
2. នឹងមានផ្ទាំងកូដមួយបង្ហាញឡើង លុបកូដចាស់ៗចេញទាំងអស់

### ជំហានទី ៣៖ ចម្លងកូដ Backend ដាក់ចូល
1. បើកឯកសារ `google-apps-script/Code.gs` នៅក្នុងគម្រោងនេះ
2. ចម្លង (Copy) កូដទាំងអស់ រួចយកទៅបិទភ្ជាប់ (Paste) ក្នុងផ្ទាំង Apps Script
3. ចុចរូប **Save** (រូបថាស) ឬចុច `Ctrl + S`

### ជំហានទី ៤៖ Deploy ជា Web App (សំខាន់បំផុត!)
1. ចុចប៊ូតុងពណ៌ខៀវ **Deploy** (ដាក់ឱ្យប្រើប្រាស់) នៅជ្រុងខាងស្តាំខាងលើ ➔ ជ្រើសរើស **New deployment** (ការដាក់ឱ្យប្រើប្រាស់ថ្មី)
2. ចុចលើរូបស្ពឺ (Select type) ➔ ជ្រើសរើស **Web app**
3. កំណត់ដូចខាងក្រោម៖
   - **Description**: `BookStock Cloud API`
   - **Execute as**: `Me (your-email@gmail.com)`
   - **Who has access**: `Anyone` *(ត្រូវតែជ្រើសរើស Anyone ដើម្បីឱ្យគ្រប់ Device អាច Sync បាន)*
4. ចុចប៊ូតុង **Deploy**
5. ប្រព័ន្ធនឹងសួររកការអនុញ្ញាត (Authorization)៖
   - ចុច **Authorize access**
   - ជ្រើសរើសគណនី Google របស់អ្នក
   - ប្រសិនបើមានផ្ទាំង "Google hasn't verified this app" ចុចលើ **Advanced** (កម្រិតខ្ពស់) ➔ ចុច **Go to ... (unsafe)**
   - ចុច **Allow** (អនុញ្ញាត)
6. បន្ទាប់ពី Deploy រួចរាល់ អ្នកនឹងទទួលបាន **Web app URL** ដែលមានទម្រង់៖
   `https://script.google.com/macros/s/AKfycbx.../exec`
7. ចម្លង (Copy) តំណភ្ជាប់ (URL) នេះទុក!

## 📱 របៀបកំណត់ឱ្យគ្រប់ Device ភ្ជាប់ទៅកាន់ Google Sheet តែមួយ

មាន ២ ជម្រើសក្នុងការកំណត់ Web App URL៖

### ជម្រើសទី ១ (ណែនាំបំផុត)៖ កំណត់ក្នុង `js/config.js` សម្រាប់ Deploy លើ Web
គ្រាន់តែបើកឯកសារ `js/config.js` រួចបិទភ្ជាប់ Web App URL របស់អ្នកត្រង់៖
```javascript
const APP_CONFIG = {
    // ដាក់ Google Apps Script Web App URL របស់អ្នកនៅទីនេះ
    DEFAULT_SHEET_URL: "https://script.google.com/macros/s/AKfycb.../exec",
    AUTO_SYNC_INTERVAL_SEC: 30,
    ...
};
```

## 🚀 របៀបដំណើរការក្នុងកុំព្យូទ័រ (Run Locally)

### វិធីទី ១៖ បើកដោយផ្ទាល់
- ចុចពីរដង (Double-click) លើឯកសារ `index.html` ដើម្បីបើកដំណើរការក្នុង Browser ណាមួយ (Chrome, Edge, Safari, Firefox)។
- មុខងារ JSONP នៅក្នុងប្រព័ន្ធនឹងដំណើរការតភ្ជាប់ Google Sheet បានយ៉ាងរលូន ទោះបីជាបើកតាមរយៈ `file:///` ក៏ដោយ។
